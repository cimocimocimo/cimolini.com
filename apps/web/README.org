* sv

Everything you need to build a Svelte project, powered by
[[https://github.com/sveltejs/cli][=sv=]].

** Creating a project
:PROPERTIES:
:CUSTOM_ID: creating-a-project
:END:
If you're seeing this, you've probably already done this step. Congrats!

#+begin_src sh
# create a new project
npx sv create my-app
#+end_src

To recreate this project with the same configuration:

#+begin_src sh
# recreate this project
npx sv@0.15.3 create --template minimal --types ts --add prettier eslint vitest="usages:unit,component" playwright tailwindcss="plugins:typography" sveltekit-adapter="adapter:static" storybook mdsvex drizzle="database:sqlite+sqlite:libsql" --install npm web
#+end_src

** Developing
:PROPERTIES:
:CUSTOM_ID: developing
:END:
Once you've created a project and installed dependencies with
=npm install= (or =pnpm install= or =yarn=), start a development server:

#+begin_src sh
npm run dev

# or start the server and open the app in a new browser tab
npm run dev -- --open
#+end_src

** Building
:PROPERTIES:
:CUSTOM_ID: building
:END:
To create a production version of your app:

#+begin_src sh
npm run build
#+end_src

You can preview the production build with =npm run preview=.

#+begin_quote
To deploy your app, you may need to install an
[[https://svelte.dev/docs/kit/adapters][adapter]] for your target
environment.
#+end_quote
